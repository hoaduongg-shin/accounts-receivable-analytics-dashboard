# Limitations and Future Development

## 1. Project Limitations

The current project has several limitations:

- The dashboard was developed and evaluated using simulated data.
- The results have not been validated using actual operational data.
- The Payment dashboard does not yet support detailed monitoring of customer payment behavior over shorter time periods.
- The current dataset does not contain sufficient logic to clearly distinguish different customer payment behaviors for monitoring and analysis.
- The dashboard has not been evaluated in an environment involving large data volumes or multiple concurrent users.
- Some components may require further adjustment when applied in an actual operational environment.

## 2. Future Development

The project can be further developed by:

- Improving the simulated data logic to better represent different customer payment behaviors.
- Enhancing the Payment dashboard to support monitoring over shorter time periods.
- Creating different simulated receivables and payment scenarios to further test the KPIs and dashboard.
- Refining the data model and dashboard based on the results of simulated testing before applying them to actual operational data.
- Validating the model using actual operational data after the simulated model has been further improved.
- Evaluating dashboard performance with larger data volumes and multiple concurrent users.
